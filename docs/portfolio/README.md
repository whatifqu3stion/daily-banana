# Portfolio capture notes

Captured from the Pages production build during the 2026-10-16 publishing pass. The capture browser used its environment date, which appears in the masthead.

- `01-setup.jpg`: real setup UI at 1280 × 960 viewport, captured full page after entering a fictional topic.
- `02-setup-mobile.jpg`: the same state at 390 × 844, captured full page.
- `03-story-choice.jpg`: real story-selection UI with the deterministic office-automation story in `tests/pages/byok.spec.ts`. Google responses were intercepted in Playwright. This is a UI demonstration, not a live model result.
- `example-comic.jpg`: a resized copy of the existing `attached_assets/0_the_cost_of_doing_business_1792075563509.png`. The original is retained unchanged. This is earlier prototype output, not output generated by the capture test. Its factual claims were not independently verified.

The declared Google fonts were supplied locally to the capture browser because external font loading was unavailable there. No interface elements were added or removed for the screenshots. JPEG conversion and resizing reduce README download size.

No real credentials or paid model calls were used. The Pages tests run the real production bundle and SDK with intercepted provider responses. The repository's separate live tests remain opt-in.

To recapture UI images, build with `npm run build:pages`, then set `PORTFOLIO_SCREENSHOTS` to an output directory and run `npm run test:pages`. `PORTFOLIO_FONTS` optionally points at a local font manifest; see the test helper. The screenshot flag does not affect the deployed app.
